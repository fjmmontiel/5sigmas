# 5sigmas remote MCP

Public, read-only MCP interface over the same bilingual knowledge graph generated by the 5sigmas MkDocs build.

## Endpoint

`https://5sigmas.com/mcp`

The Worker serves Streamable HTTP with Cloudflare's stateless `createMcpHandler`.

## Tools

- `search(query)` — OpenAI company-knowledge/deep-research compatible search. Returns `{ results: [{ id, title, url }] }`.
- `fetch(id)` — OpenAI-compatible full-content retrieval. Returns `{ id, title, text, url, metadata }`.

Both tools are read-only and idempotent, return absolute canonical URLs, and read live data from:

- `https://5sigmas.com/agent/knowledge.json`
- `https://5sigmas.com/en/agent/knowledge.json`

There is no parallel content store or vector database to synchronize.

## Local checks

```bash
npm install
npm test
npm run deploy:dry
```

After deployment:

```bash
npm run verify:live -- https://5sigmas.com/mcp
```

The live verifier connects with the official MCP v2 client using automatic protocol negotiation, lists the tools, runs representative searches and fetches their top results.

## Deployment

GitHub Actions deploys the Worker for changes merged to `main` using the repository's existing Cloudflare credentials:

- `CLOUDFLARE_API_TOKEN`
- `R2_ACCOUNT_ID` as the Cloudflare account id

The token must be authorized for Workers Scripts and Workers Routes on the `5sigmas.com` zone.
