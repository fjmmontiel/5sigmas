  <section class="li-caption-panel"><p>Una alucinación cambia de escala en cuanto el sistema puede actuar. Mientras se queda en un chat, el error produce texto incorrecto. Cuando el sistema puede usar herramientas o mover algo en el entorno, el error puede convertirse en una acción real.</p>
<p>Una alucinación en un chat inventa una frase. Una alucinación en un agente puede borrar una base de datos o lanzar una acción física equivocada. Ese es el cambio importante: cuando percepción y acción van unidas, el error deja de ser solo un problema de lenguaje y pasa a ser un problema operativo.</p>
<p>La trazabilidad también se complica. El sistema puede mostrar una cadena de razonamiento aparentemente coherente y seguir partiendo de una percepción falsa. Si ese fallo entra en memoria y vuelve al ciclo de percepción, acción y revisión, el desvío se propaga.</p>
<p>Por eso la multimodalidad con agencia no eleva solo el potencial del sistema. También eleva la exigencia de supervisión, control humano y mecanismos que frenen acciones sensibles a tiempo.</p>
<p>En el artículo conecto ese salto con confinamiento por etapas, supervisión y sistemas que pueden abortar antes de causar daño. (<a href="https://5sigmas.com/series/multimodalidad-iag/05-riesgos/">https://5sigmas.com/series/multimodalidad-iag/05-riesgos/</a>).</p>
