  <section class="li-caption-panel"><p>Los modelos actuales ya superan a mucha gente en tareas concretas de lenguaje, código, análisis y síntesis. Ese avance es real y no necesita exageración.</p>
<p>La parte difícil empieza cuando se confunde rendimiento localizado con inteligencia general. Un modelo puede resolver problemas complejos dentro de una ventana de contexto y aun así fallar en causalidad robusta, conocimiento físico, memoria persistente o generalización fuera de lo visto.</p>
<p>La diferencia importa porque muchas demos prueban fluidez, no comprensión del mundo. Un sistema puede explicar una escena o escribir una solución plausible sin tener una representación causal suficiente para actuar de forma fiable cuando cambian las condiciones.</p>
<p>El debate serio no está entre &quot;todo es humo&quot; y &quot;ya es AGI&quot;. Está en identificar qué capacidades son sólidas y cuáles siguen siendo frágiles.</p>
