  <section class="li-caption-panel"><p>Un algoritmo no aprende en abstracto. Aprende desde una señal concreta, y esa señal marca sus límites.</p>
<p>Cuando tienes ejemplos etiquetados, puedes entrenar un sistema supervisado. Cuando solo tienes datos sin respuesta correcta, buscas estructura. Cuando el propio dato permite fabricar la tarea, aparece el aprendizaje auto-supervisado. Y cuando el sistema actúa y recibe consecuencias, entras en refuerzo.</p>
<p>La diferencia parece académica, pero aparece en cada proyecto real. Si no tienes etiquetas fiables, el mejor clasificador del mundo no arregla el problema. Si la tarea depende de una cadena de decisiones, tratarla como una predicción aislada deja fuera media realidad.</p>
<p>Elegir &quot;IA&quot; empieza bastante antes de elegir arquitectura. Empieza preguntando qué profesor tiene el sistema.</p>
