Retrieval ≠ ensamblado ≠ grounding

Recuperar candidatos es sólo el principio: la aplicación decide qué evidencia merece entrar

La similitud ayuda a encontrar candidatos. No prueba que sean actuales, autoritativos, compatibles entre sí ni suficientes para sostener una afirmación. El ensamblador aplica esas políticas antes de construir el contexto.

flujo admitido / control enlace afirmación → evidencia línea gruesa = validación contra autoridad actual

Recupera un conjunto amplio de candidatos y ensambla sólo la evidencia elegible. Un resultado relevante sigue siendo sólo un candidato. El contexto final debe conservar versión, autoridad, permisos y conflictos; y cada afirmación material debería poder trazarse a la evidencia que realmente entró en Aₜ.
