TELEMETRÍA ≠ VEREDICTO

Un fallo de producción sólo entra al eval cuando su mecanismo es reproducible

La señal detecta; el trace reconstruye; la taxonomía formula una causa; el caso mínimo la hace falsable; el regression gate valida la reparación; producción confirma si la familia de fallo realmente dejó de aparecer.

flujo de reparación/release evidencia y feedback

Lectura: una métrica o trace inicia una investigación; no aprueba ni suspende por sí solo. Si no puedes reproducir el mecanismo, mejora instrumentación. Si puedes, minimiza y redacta el caso, protege la clase de equivalencia con neighbors, versiona el verifier y sólo considera cerrado el loop cuando la reparación vuelve a producción y la familia de fallo deja de recurrir bajo observación fiable.
