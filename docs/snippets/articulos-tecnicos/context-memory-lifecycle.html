Memory lifecycle · semántica ≠ persistencia

La memoria útil necesita rutas distintas para recordar, consolidar, verificar y reanudar

Working state es lo que condiciona la decisión actual. Episodios y conocimiento semántico pueden persistir fuera del contexto. El system of record conserva autoridad de negocio. Un checkpoint reanuda ejecución, pero no convierte su snapshot en memoria semántica.

flujo de estado o acción derivación / checkpoint línea gruesa = autoridad actual

Persistir no hace equivalentes estos stores. Episodios registran eventos, memoria semántica consolida conocimiento derivado, el system of record gobierna estado de negocio y el checkpoint existe para reanudar ejecución. Sólo el subconjunto seleccionado entra en Wₜ.
