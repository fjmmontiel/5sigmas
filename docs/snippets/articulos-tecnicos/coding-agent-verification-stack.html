Verificación · review · stop

«Done» exige evidencia ligada al candidato exacto

Un test verde es una señal. El harness sólo puede cerrar cuando el contrato actual, el commit actual y todas las verificaciones obligatorias siguen alineados.

Candidato
head SHA · entorno · contrato Checks deterministas
tests · tipos · lint · estado Diff review
scope · API · config · tests Juicio adicional
rubric · humano · caveats Freshness gate
mismo SHA · misma evidencia Decisión
accept · rework · handback
Regla de cierre: cualquier cambio posterior al candidato invalida la evidencia que dependa de ese estado. «El agente dice que terminó» no sustituye tests, revisión ni comprobación del resultado real.
