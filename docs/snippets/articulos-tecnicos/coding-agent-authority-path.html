Autoridad · policy · credenciales

Una tool call no es todavía permiso para producir un efecto

La propuesta del modelo cruza varias fronteras independientes antes de tocar un sistema externo.

Contexto
repo · issue · web · output de tools Propuesta
tool + argumentos Policy
allow · ask · deny Approval
acción concreta · scope · vigencia Sandbox
filesystem · proceso · red Credencial
identidad · permisos · expiración Efecto + evidencia
resultado externo · audit · verifier
Defensa en profundidad: una frontera no sustituye a las demás. La sandbox puede impedir escribir fuera del workspace y aun así un token con demasiados permisos puede autorizar un efecto remoto. Un approval humano puede autorizar una llamada concreta y aun así no demostrar que sus argumentos sean seguros.
