Autoridad · policy · credenciales

Una tool call sólo produce un efecto cuando varias fronteras independientes lo permiten

La propuesta del modelo no es autoridad. Tool surface, policy, approval, sandbox, credencial y controles remotos responden preguntas distintas.

flujo autorizado o evaluadofrontera de confianza/capacidadcambio que invalida una aprobación
La conjunción es la idea: exponer una tool no concede autoridad; una aprobación no amplía la sandbox; la sandbox local no reduce por sí sola los scopes de una credencial remota; y un approval deja de representar la decisión humana si cambia el request que se ejecutará. Cada salida, incluida una denegación, debe dejar evidencia suficiente para reconstruir qué autoridad existía realmente.
