Contrato estable · estrategia revisable

Replanificar no cambia qué significa terminar

La spec fija objetivo, scope y aceptación. El plan puede cambiar cuando una observación invalida una hipótesis.

Petición + reglas
intención · policy del repo Contrato vN
goal · scope · acceptance · stop Plan / grafo vM
dependencias · hipótesis Ejecutar + observar
si cambia la evidencia → replan Verificar + checkpoint
estado · inputs · verification_head_sha Done / handback
evidencia completa o decisión pendiente
Replan cambia la estrategia manteniendo el contrato. Enmienda cambia qué resultado está autorizado y obliga a revalidar la evidencia afectada. Un checkpoint sólo demuestra continuidad si declara qué estado captura y a qué revisión pertenece.
