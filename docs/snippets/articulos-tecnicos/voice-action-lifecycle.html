Conversación ≠ efecto

Un barge-in corta una pista; no rebobina la operación

Las tres lanes comparten tiempo, pero no autoridad. La conversación puede avanzar mientras op_42 sigue siendo una obligación pendiente del sistema.

Regla de producción: cancel speech cambia la conversación; no cambia por sí solo la verdad de operation_id. Si pierdes la respuesta después de enviar una mutación, UNKNOWN significa «reconciliar», no «reintentar». Sólo el sistema de registro puede resolver qué efecto existe realmente.
