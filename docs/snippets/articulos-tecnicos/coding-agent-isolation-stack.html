Aislamiento ≠ una primitive

Worktree, sandbox e integración protegen fronteras diferentes

Separar archivos no restringe la red; restringir procesos no hace compatibles dos diffs.

Repo + base SHA
historia · refs · revisión inicial Vista de contexto
lo que el modelo observa Workspace / worktree
HEAD · índice · dirty state Sandbox
filesystem · red · procesos · identidad Integración
branch · commit · PR · revalidación
Worktree separa estado mutable entre trayectorias; no es una security boundary. Sandbox limita capacidades de ejecución; no resuelve conflictos semánticos. La entrega sólo es atribuible si el harness conserva base SHA, identidad del workspace, policy efectiva y el SHA exacto sobre el que pasaron los verificadores.
