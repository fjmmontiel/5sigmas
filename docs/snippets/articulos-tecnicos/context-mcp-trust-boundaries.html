MCP ≠ confianza implícita

El host conecta servidores sin cederles la política de contexto ni de acciones

Los clientes MCP crean conexiones interoperables. El host conserva aislamiento, consentimiento y composición; un tool con efectos reales todavía debe cruzar autorización y la frontera del sistema downstream.

acción / controldatos o instrucciones hacia el host

Interoperabilidad no es autoridad. MCP estandariza la ruta entre host y server; el host sigue decidiendo qué contenido entra al modelo y qué acción puede cruzar una frontera. Una llamada exitosa tampoco demuestra que el efecto downstream fuera autorizado o correcto.
