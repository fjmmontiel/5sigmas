Modelo ≠ harness

La autonomía está en el bucle que vuelve a alimentar al modelo

El modelo propone una acción. El harness conserva estado, aplica política, ejecuta, observa y decide si existe evidencia para continuar o parar.

flujo causalestado persistente del harness
La diferencia no es «usar tools». Es cerrar el feedback loop: la observación de una acción cambia el estado con el que se construye el siguiente contexto. El modelo sólo participa en el tramo contexto → propuesta; la continuidad, la política de ejecución, la evidencia y la decisión continue/stop pertenecen al harness. Si el runtime no puede reconstruir ese estado, no existe una trayectoria reproducible que continuar.
