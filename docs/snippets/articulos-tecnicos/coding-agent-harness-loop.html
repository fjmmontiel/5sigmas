Modelo ≠ harness

El modelo propone; el harness convierte propuestas en trabajo sobre un repositorio

La autonomía aparece cuando un runtime mantiene el bucle, ejecuta tools bajo política y decide cuándo verificar, continuar o devolver control.

Contrato de tarea
objetivo · alcance · restricciones Modelo
propone la siguiente acción Harness + entorno
contexto · tools · sandbox · estado Verificador / stop
tests · diff · política · handback
El paso crítico está entre proponer y actuar. El harness decide qué contexto recibe el modelo, valida permisos, ejecuta shell/ediciones/git en un workspace, devuelve la observación al siguiente turno y conserva la continuidad causal y el estado necesarios para repetir. Un test verde o un diff revisable son señales para decidir si el bucle continúa; no son propiedades del modelo por sí solo.
