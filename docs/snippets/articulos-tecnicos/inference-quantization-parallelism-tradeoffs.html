La cuantización sólo reduce los tensores que realmente se cuantizan y sólo acelera si el hardware/runtime ejecuta un kernel favorable. El paralelismo sólo ayuda si el trabajo ganado compensa comunicación, sincronización y estado replicado.

Lectura: `W4A16` dice qué precisión usan pesos y activaciones; no dice qué kernel se ejecuta, cuánto ocupan las escalas ni qué calidad conserva el modelo. `TP=4` dice cómo se reparte parte del modelo; no dice cuánto tarda el collective ni si el interconnect puede sostenerlo. Bits y número de GPUs son entradas del sistema, no métricas de rendimiento.
