Paquete ≠ contexto ≠ autoridad

Cada componente cruza una frontera distinta

Un plugin distribuye componentes. Una skill entra en contexto cuando se activa. Un subagente cruza una frontera de delegación. Un hook intercepta eventos. Los efectos externos siguen necesitando política, autorización y verificación.

control / autoridad contexto / evidencia empaquetado / definición

La separación útil no es «extensión sí/no». Es qué componente se empaqueta, qué entra en el contexto del modelo, qué ejecución recibe capacidades, qué evento puede bloquearse y qué autoridad hace falta antes de cambiar estado externo.
