Paging decide dónde vive el KV; continuous batching decide quién está activo

Los bloques lógicos de una secuencia pueden mapearse a páginas físicas no contiguas. Cuando una petición termina, libera páginas; el scheduler puede admitir otra petición en una iteración posterior. Mover bloques a host añade capacidad, pero también movimiento.

Lectura: PagedAttention o un KV cache paginado cambia la relación entre bloques lógicos y memoria física. Continuous batching cambia el conjunto de peticiones activas en cada iteración. El vínculo entre ambos es la capacidad: terminar una petición libera estado y puede permitir una nueva admisión. Offload añade otro tier; no convierte memoria lenta en VRAM gratuita.
