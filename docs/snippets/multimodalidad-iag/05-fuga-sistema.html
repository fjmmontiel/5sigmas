Ataque multimodal · dos fases
La herramienta no es el primer fallo.
Primero se degrada el estado de decisión del modelo; después ese estado puede alcanzar una herramienta con efectos externos. Recorre la cadena en orden.
Contenido no fiableimagen con instrucciones embebidas
→
Modelomezcla datos e instrucciones
→
Estado degradadolas restricciones dejan de gobernar la siguiente decisión
Control que corta esta fase:separar contenido no confiable de instrucciones y evaluar la salida antes de convertirla en una nueva orden.
Estado degradadoel modelo propone una acción no autorizada
→
Tool privilegiadaenvío, escritura o llamada externa
→
Efecto externoel daño ya sale del contexto del modelo
Control que corta esta fase:mínimo privilegio + confirmación para efectos sensibles + política explícita entre decisión y ejecución.
Regla de arquitecturaUna inyección exitosa no debe equivaler automáticamente a una acción exitosa. Entre contenido → decisión → herramienta deben existir fronteras independientes.
