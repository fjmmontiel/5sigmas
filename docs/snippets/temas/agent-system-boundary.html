ARQUITECTURA DEL AGENTE
El modelo decide; el runtime convierte esa decisión en un sistema controlable
Un agente fiable separa razonamiento, autoridad, estado y efectos externos. El LLM propone el siguiente paso; el runtime conserva la fuente de verdad y aplica las reglas antes de actuar.
