Los proyectos reales validan piezas concretas, no el datacenter orbital completo
La prueba relevante no es “hay hardware en órbita”. La prueba relevante es qué parte del argumento valida cada proyecto: cómputo, almacenamiento, enlaces, operación continua o escala térmica.
Cómputo Storage Enlaces Runtime Escala térmica

Starcloud

Demostración de compute COTS avanzado en órbita y entrenamiento de un modelo simplificado, no una cloud orbital general.

Valida: compute COTSNo valida: MW térmicos

Axiom / Spacebilt

Nodos iniciales ODC y almacenamiento de alta capacidad en LEO. Prueba piezas de infraestructura, no una cloud madura.

Valida: storage + enlacesNo valida: cloud general

D-Orbit AIX

Inferencia útil sobre observación, con reducción radical de downlink.

Valida: data gravityNo valida: entrenamiento orbital

Three-Body / ADA

Valida: mesh + repartoNo valida: economía final

Tiansuan / BUPT-1

Valida: runtime orbitalNo valida: densidad IA
