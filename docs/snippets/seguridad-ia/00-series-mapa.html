Mapa de serie
Cómo pasa el riesgo de un documento a una acción
La serie sigue el camino desde un contenido externo hasta una acción del sistema. En cada etapa explica qué puede fallar y qué control puede detenerlo.
01
Una orden oculta en un documento
Un documento externo contiene una orden que el sistema puede confundir con una instrucción válida.
02
Pedir lo mismo de muchas formas
Un atacante cambia la petición hasta encontrar una respuesta que debería estar bloqueada.
03
Guardar una señal peligrosa
Un documento, una memoria o un modelo conserva una señal que puede reaparecer más tarde.
04
Probar el camino completo
La evaluación sigue el sistema desde la entrada hasta la acción, no solo la respuesta de texto.
05
Limitar lo que el sistema puede hacer
Cuarentena, permisos mínimos, registros y recuperación reducen el daño.
