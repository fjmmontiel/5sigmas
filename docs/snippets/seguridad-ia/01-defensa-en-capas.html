La defensa útil corta rutas, no solo frases
Separar lectura de contenido no confiable, decisión privilegiada y ejecución de herramientas reduce la ruta de ataque mucho más que un system prompt más largo.
1. Ingesta
contenido externo no confiable
sanitización y validación básica
→
2. Cuarentena
LLM sin tools
resume, etiqueta o extrae estructura
→
3. Decisión
LLM privilegiado
ve salida estructurada, no el texto crudo
→
4. Acción
tools con scope mínimo
permiso concreto, logs y abortos
Controles transversales
mínimo privilegio salida estructurada human approval streaming guards telemetría kill switch
Lo que no basta
Más instrucciones en el system prompt, filtros de keywords aislados o un guardrail sin separación de privilegios siguen dejando abierto el mismo camino entre texto hostil y acción sensible.
