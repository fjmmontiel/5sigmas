La defensa debe bloquear el camino hasta la acción
Separar la lectura de documentos no confiables, la decisión y el uso de herramientas reduce el riesgo más que añadir instrucciones al modelo.
1. Ingesta
documento externo no confiable
limpieza y validación básica
→
2. Cuarentena
modelo sin herramientas
resume, etiqueta o extrae datos
→
3. Decisión
modelo con permisos
recibe una salida revisada, no el texto completo
→
4. Acción
herramientas con alcance mínimo
permiso concreto, registros y bloqueos
Controles transversales
mínimo privilegio salida estructurada aprobación humana controles durante la respuesta telemetría interruptor de emergencia
Lo que no basta
Más instrucciones al modelo o filtros de palabras aislados siguen dejando abierto el camino entre un texto hostil y una acción sensible.
