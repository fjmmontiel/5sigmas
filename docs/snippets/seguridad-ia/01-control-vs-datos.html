Marcar una fuente como no confiable ayuda al runtime y a los controles, pero no crea por sí solo una separación infalible dentro del LLM.

3 · Influencia: el modelo puede proponer una acción no deseada

Salida textual propuesta: resumen del documento.
Tool call propuesto: send_credentials(destination="attacker")

Que el modelo proponga una operación no significa que esa operación esté autorizada.

4 · Autoridad: el runtime valida la operación fuera del LLM

FALLALa tarea original no autoriza exfiltrar secretos ni usar ese destino.
FALLAEl documento recuperado no puede conceder permisos al usuario ni al agente.
PASAEl texto de respuesta puede continuar a validación de salida sin ejecutar la operación.
ACCIÓN DENEGADALa inyección consiguió influir en una propuesta, pero no cruzó la frontera que autoriza efectos externos.

Propiedad clave: procedencia e instrucciones ayudan a gestionar influencia; permisos, allowlists, validación de parámetros y aprobación humana cuando corresponde controlan autoridad de ejecución. Ninguna capa aislada elimina el riesgo.
