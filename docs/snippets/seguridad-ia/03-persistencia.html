Persistir crea copias; revocar exige cortar todas las rutas

Este modelo separa la fila de memoria original de sus derivados. Una consulta futura puede recuperar una copia aunque el turno que la creó haya terminado, y borrar solo el origen no garantiza que la influencia desaparezca.

Contraejemplo: eliminar la fila de memoria y conservar el índice o un resumen derivado deja una ruta de recuperación. La revocación solo es completa cuando esos derivados dejan de ser alcanzables y una regresión confirma que la señal no reaparece.
