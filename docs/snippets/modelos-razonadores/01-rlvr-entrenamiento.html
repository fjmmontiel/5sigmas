VERIFICACIÓN
Un verificador externo comprueba la respuesta final. La comprobación es objetiva: no se evalúa la forma, solo la corrección.
Math: ¿coincide con el resultado correcto? · Code: ¿pasan los tests unitarios?

RECOMPENSA
Señal binaria o escalar. Las cadenas que producen respuestas correctas refuerzan las estrategias usadas; las incorrectas las debilitan.
+1 si correcto · 0 si incorrecto · el gradiente actualiza los pesos del modelo
El bucle se repite con millones de problemas. El modelo no aprende "la respuesta" — aprende qué estrategias de razonamiento funcionan.
PREENTRENAMIENTO
Predicción del siguiente token
Objetivo
Imitar el texto existente en internet — artículos, libros, código, conversaciones
Señal
Cross-entropy sobre el token siguiente. Densa: cada token genera gradiente
Resultado
El modelo aprende patrones estadísticos del lenguaje y conocimiento factual del mundo
Límite
Los libros muestran soluciones limpias, no el proceso de búsqueda que las produjo
RLVR POST-ENTRENAMIENTO
Optimización por recompensa verificable
Objetivo
Maximizar la tasa de respuestas correctas en problemas verificables — matemáticas, código, lógica
Señal
Binaria por episodio: correcta o incorrecta. Escasa — solo al final de cada intento
Resultado
El modelo descubre estrategias de búsqueda: retroalimentación, verificación intermedia, exploración de caminos alternativos
Ventaja
No necesita datos humanos de razonamiento — el verificador actúa como juez objetivo infinitamente escalable
GRPO (Group Relative Policy Optimization) es el algoritmo de entrenamiento que usó DeepSeek R1. Elimina la necesidad de un modelo crítico separado.
ENTRADA
Problema
Un problema matemático o de código con respuesta verificable objetivamente
MUESTREO
G intentos independientes
El modelo genera G respuestas distintas para el mismo problema (ej. G=8). Cada una tiene su propia cadena de pensamiento
EVALUACIÓN
Recompensas r₁…r_G
Cada intento recibe una recompensa verificada. La ventaja de cada intento se calcula como su desviación del promedio del grupo: Aᵢ = (rᵢ − r̄) / std
ACTUALIZACIÓN
Gradiente relativo
Los intentos mejores que el promedio del grupo refuerzan sus tokens de razonamiento. Los peores los penalizan. Sin modelo crítico separado.
Sin modelo crítico
PPO clásico necesita entrenar un modelo de valor separado. GRPO usa el grupo como referencia — ahorra memoria y simplifica el pipeline
Sin datos de razonamiento
No se necesitan ejemplos de CoT humanos. El modelo descubre sus propias estrategias de exploración guiado solo por el resultado verificado
Resultado emergente
Durante el entrenamiento de R1, el modelo desarrolló espontáneamente comportamientos de retroalimentación, verificación y exploración de caminos — sin que se le indicara hacerlo
