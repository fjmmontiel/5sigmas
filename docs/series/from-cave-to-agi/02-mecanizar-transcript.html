Un acarreo conecta dos posiciones

Una rueda de unidades representa nueve y otra de decenas representa cero.

Añadir una unidad hace volver la primera a cero y avanzar la segunda a uno.

El mecanismo representa diez sin que una persona deba recordar el acarreo.

Cambiar el patrón, conservar el mecanismo

Un patrón de perforaciones codifica instrucciones para seleccionar posiciones.

Una segunda tarjeta activa otra secuencia sin reconstruir el mecanismo.

Separar instrucciones y ejecución permite repetir procedimientos distintos.

Una operación lógica puede gobernar un circuito

Dos interruptores en serie deben estar cerrados para completar el recorrido.

Si A o B permanece abierto, la salida es cero.

Con ambos cerrados, la salida es uno: el circuito implementa A AND B.

Una regla local puede recorrer una cinta

La cinta contiene tres unos seguidos de una celda vacía.

La regla avanza a la derecha mientras lee un uno.

Al encontrar la celda vacía, escribe otro uno y se detiene: ha incrementado un conteo unario.

Instrucciones y datos pueden residir en memoria

La memoria contiene instrucciones de cargar, sumar y guardar, además de dos datos.

La unidad ejecutora lee una instrucción cada vez y actualiza su registro.

En este ejemplo carga tres, suma cuatro y guarda siete.

Cuatro alternativas equiprobables requieren dos bits

Un mensaje puede ser A, B, C o D, con la misma probabilidad.

Dos decisiones binarias distinguen las cuatro posibilidades.

Los bits cuantifican la incertidumbre de esta elección, no el significado del mensaje.
