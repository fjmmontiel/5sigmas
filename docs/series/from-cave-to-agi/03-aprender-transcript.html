Las excepciones amplían la base de reglas

Una regla inicial resuelve un conjunto acotado de casos.

Un caso nuevo exige una excepción y puede entrar en conflicto con otra regla.

El mantenimiento crece cuando cambian las condiciones; automatizar una regla no resuelve todas sus excepciones.

Ajustar los ejemplos no basta para generalizar

Una curva flexible puede atravesar todos los puntos de entrenamiento.

Los puntos reservados permiten comprobar si ese ajuste conserva el patrón fuera de la muestra.

Un error de entrenamiento pequeño no garantiza un error pequeño en datos nuevos.

El gradiente indica una dirección local

Usamos la pérdida L igual a w menos tres al cuadrado, empezando en w igual a cero.

El gradiente vale menos seis. Un paso de tamaño cero coma dos mueve w a uno coma dos.

La pérdida baja de nueve a tres coma veinticuatro; el paso siguiente vuelve a calcular el gradiente.

Una representación cambia la separación posible

En XOR, las dos esquinas opuestas con una sola entrada activa tienen etiqueta uno.

Ninguna recta separa esas dos esquinas de las otras dos en el plano original.

Una transformación no lineal permite distinguir el caso de exactamente una entrada activa.

El error se propaga mediante derivadas

Una red compone operaciones: x pasa por dos pesos antes de producir una salida.

La regla de la cadena conecta cómo cambia la pérdida con cada operación intermedia.

Backpropagation reutiliza esas derivadas para ajustar pesos en varias capas.

Una ventana corta descarta contexto lejano

Un modelo de trigramas condiciona el siguiente token a los dos anteriores.

Dos frases con el mismo final reciben ese mismo contexto corto, aunque antes hablen de cosas diferentes.

Limitar la memoria simplifica el modelo y elimina dependencias que queden fuera de la ventana.
