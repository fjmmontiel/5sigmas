La ventana no es el budget

En este ejemplo, la capacidad total es de 64 mil tokens.

Reservamos 8 mil para salida, 4 mil de margen y 4 mil para instrucciones obligatorias.

Quedan 48 mil para información dinámica. No es una propiedad universal del modelo.

La spec no debe desaparecer

Un bloque de logs de 42 mil tokens desplaza archivos necesarios dentro de un budget de 48 mil.

Extraemos sólo los fallos relevantes y conservamos una referencia al log completo.

El contrato y los archivos vuelven a caber. La extracción debe conservar el error que importa.

Un resumen puede perder la regla

La fuente dice: devolver en catorce días, excepto artículos abiertos.

Un resumen conserva el plazo y elimina la excepción. Parece correcto, pero cambia la decisión.

La prueba de compactación comprueba ambas condiciones y rechaza esa pérdida.

El derivado necesita origen

El resumen S deriva del documento en revisión A mediante una transformación con pérdida.

Cuando cambia la revisión, S deja de estar validado para el estado actual.

La procedencia permite recuperar el fragmento afectado, sin regenerar todo por defecto.

Cache y resumen no hacen lo mismo

Reutilizar un prefijo en caché evita repetir trabajo de procesamiento, según el contrato del proveedor.

El contenido sigue formando parte de la entrada lógica. No hemos seleccionado ni resumido nada.

Compactar sustituye la representación anterior por otra. Esa transformación sí puede perder información.

Un enlace debe recuperar la versión

El contexto guarda un ID corto para el archivo A, no todas sus líneas.

Cuando hace falta el detalle, la lectura solicita la revisión A y verifica su identidad.

Si sólo aparece B, no se presenta como A. El ahorro de contexto crea una obligación de recuperación.
