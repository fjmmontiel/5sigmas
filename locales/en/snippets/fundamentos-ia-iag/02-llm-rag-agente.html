SYSTEM COMPOSITION

More capability means more moving parts

Plain LLM

Prompt + model → answer

Best when general parametric knowledge is enough.
LLM + RAG

Query → retrieve → context → answer

Adds current/private evidence without changing model weights.
Agent

Observe → plan → tool → verify → repeat

Adds actions and adaptive multi-step control.
Complexity is not quality

Use the simplest architecture that satisfies the task. RAG adds retrieval failure modes; agents add planning, tool, state and compounding-error failure modes.
