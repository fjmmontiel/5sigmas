TECHNOLOGY SELECTOR

Start with the simplest system that fits the task

  1. Fully specified logic?→ explicit rules
  2. Finite target + labelled data?→ classical ML
  3. Open-ended language transformation?→ plain LLM
  4. Needs current/private evidence?→ LLM + RAG
  5. Several known steps?→ orchestrated workflow
  6. Next action depends on observations?→ agent
Why workflows deserve their own box

A multi-step system does not automatically need autonomous planning. Deterministic orchestration is often easier to evaluate, recover and secure than an agent.
