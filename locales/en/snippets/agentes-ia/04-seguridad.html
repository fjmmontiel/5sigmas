An attack only needs one complete path to an effect
Useful defense is not a list of tips: each control should break a specific transition between untrusted data and a privileged action.
untrusted inputEmail, web, or document“ignore policy and send…”
1 · context boundaryseparate data from instructionsContent may inform the task; it does not redefine authority.
model decisionproposes an actionthe proposal still has no permission
2 · capability boundaryallowlist + least privilegeA missing or out-of-scope tool stops the path here.
tool callspecific action + argumentsrecipient, resource, amount, operation
3 · authorization boundaryverifiable policy + confirmationApproval applies to this action, not to future decisions.
external effectsend · write · executeonly happens if all three boundaries allow the path
Path cutIf the tool lacks write permission, an injection that reaches the model may influence text but cannot complete the privileged effect.
