AI electricity demand has an up-front phase and a recurring phase

Building a model consumes a concentrated block of data-center compute. Serving the model consumes electricity again every time users or applications request work.

Model building
Data-center compute→bounded build period→deployable model

Large electricity use is concentrated into a finite project window before the model is used by customers.

Serving
Request→data-center compute→response

Electricity demand repeats with every request and therefore grows with adoption, usage intensity and response length.

total serving demand≈requests×compute per request
Efficiency per request can improve while total electricity demand still rises if usage grows faster than the efficiency gain.
