AI capacity is a physical supply chain

More model demand becomes useful capacity only when several constraints clear at the same time.

GridPower capacity + interconnection
→
HardwareAccelerators + memory + networking
→
CoolingHeat rejection + water strategy
→
FacilitiesLand + substations + fiber
→
OperationsPeople + software + reliability

Key idea: the slowest constrained layer sets the pace. Buying more accelerators does not create deployable compute if power, cooling or interconnection is missing.
