ANSWER → ACTION

The same perceptual error has different consequences

Chat only

Wrong perception → wrong textual answer.

Tool / robot

Wrong perception → external state change.

Required escalation

As consequence rises, require stronger grounding, secondary verification, bounded action spaces and explicit approval at irreversible boundaries.

Abstention is a capability

A safe system should be able to say that the evidence is insufficient instead of converting every ambiguous perception into a confident decision.
