Seen evaluation data can look like generalization

Public benchmark→ web mirrors / captions / discussions →Pretraining corpus→Inflated test score
Why image leakage is hard to detect

The same underlying image can appear with different crops, compression, captions or filenames. Exact-text or exact-hash deduplication misses near-duplicates.

Better practice

Use fresh/protected test sets when possible, similarity searches for duplicates and explicit contamination reporting alongside headline scores.
