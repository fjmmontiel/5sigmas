VISUAL INSTRUCTION TUNING

Alignment is not the same as following a visual instruction

Image+Instruction+Expected response
What this stage teaches

The model learns how to use visual evidence to satisfy a requested task—compare, transcribe, localize, explain or answer—not merely whether an image and caption are semantically related.

Why synthetic data helps

A strong language model can generate large instruction/response datasets cheaply, but systematic blind spots in those synthetic examples become training bias.
