How a reasoning model is trained
Reinforcement Learning with Verifiable Rewards: the loop that turns failed attempts into deeper reasoning strategies.
1
∑
PROBLEM
The model receives a problem with a verifiable answer: mathematics, code or formal logic.
"Prove that √2 is irrational"
2
⋯
CHAIN OF THOUGHT
The model generates internal reasoning tokens. There is no rigid output format: it can explore, backtrack and revisit premises.
"Assume √2 = p/q… then 2q² = p²… p is even… q is even… contradiction."
3
✓
VERIFICATION
An external verifier checks the final answer. The check is objective: it scores correctness, not presentation.
Math: does it match the correct result? · Code: do the unit tests pass?
4
R
REWARD
A binary or scalar signal. Chains that produce correct answers reinforce the strategies they used; incorrect ones weaken them.
+1 if correct · 0 if incorrect · the gradient updates the model weights
The loop repeats across millions of problems. The model does not learn "the answer"—it learns which reasoning strategies work.
PRETRAINING
Next-token prediction
Objective
Imitate existing text from the internet—articles, books, code and conversations
Signal
Cross-entropy on the next token. Dense: every token produces a gradient
Result
The model learns statistical language patterns and factual knowledge about the world
Limit
Books show clean solutions, not the search process that produced them
RLVR POST-TRAINING
Optimization with verifiable rewards
Objective
Maximize correct-answer rate on verifiable problems—mathematics, code and logic
Signal
Binary per episode: correct or incorrect. Sparse—only at the end of each attempt
Result
The model discovers search strategies: backtracking, intermediate verification and exploration of alternative paths
Advantage
No human reasoning traces are required—the verifier acts as an objective judge that can scale
GRPO (Group Relative Policy Optimization) is the training algorithm used by DeepSeek R1. It removes the need for a separate critic model.
INPUT
Problem
A mathematics or coding problem whose answer can be verified objectively
SAMPLING
G independent attempts
The model generates G different answers to the same problem (for example G=8). Each has its own reasoning chain
EVALUATION
Rewards r₁…r_G
Each attempt receives a verified reward. Its advantage is its deviation from the group average: Aᵢ = (rᵢ − r̄) / std
UPDATE
Relative gradient
Attempts above the group average reinforce their reasoning tokens; worse attempts penalize them. No separate critic model is required.
No critic model
Classic PPO needs a separate value model. GRPO uses the group as its reference, saving memory and simplifying the pipeline
No reasoning traces
Human CoT examples are not required. The model discovers its own exploration strategies guided only by the verified result
Emergent result
During R1 training, the model spontaneously developed backtracking, verification and path-exploration behaviors without being explicitly told to do so
