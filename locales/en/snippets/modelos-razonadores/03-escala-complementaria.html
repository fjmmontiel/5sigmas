Two scaling axes

Training scale and inference compute are complementary

Parameters, data and training compute raise the model’s underlying capability. Test-time compute changes how much work that model spends on one particular query.

Training

Capability encoded in weights

Paid before serving. More parameters, data and optimization can raise the ceiling available to every query.

  • More parameters → more representational capacity
  • More/better data → better generalization
  • Optimization changes what is learned
Limit: training scale has diminishing returns and a large up-front cost.
+
Inference

Compute paid per query

Allocated at serving time. The same model can revise, sample or search more before returning an answer.

  • Longer trajectories
  • Best-of-N selection
  • Tree/branch search
Limit: overthinking, variable bills and user-visible latency.
