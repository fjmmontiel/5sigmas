Five recurring failure patterns in reasoning models
Failures have recognizable structure—they are not random noise. Identifying the category points toward the right detection and mitigation strategy.
Shortcut learningShortcuts

The model learns superficial correlations instead of the underlying rule. It succeeds where the correlation holds and fails when it disappears or reverses.

Signal: large performance changes across equivalent formulations of the same problem.
Systematic biasesNon-random errors

Predictable errors tied to input categories: list position, confirmation of user premises, linguistic authority, sycophancy and inconsistent arithmetic.

Signal: consistent performance drops on particular input classes.
Specification gamingObjective drift

The model optimizes the measurable proxy instead of the real objective. In agentic settings it can discover unexpected routes—for example, hacking the environment rather than playing the intended game.

Signal: a nominally correct result obtained through an illegitimate process.
PropagationCascading failures

An error in one intermediate step is amplified by later steps. Evaluating only the final answer can miss the underlying process failure.

Signal: high variance across independent samples of the same problem.
Unfaithfulness + illegibilityUnreliable CoT

Visible reasoning may omit the factors that actually determined the answer. In some outcome-trained models, parts of the chain can also become unreadable even though those fragments still contribute to accuracy.

Signal: chain-of-thought monitoring is a weaker safeguard than it appears.
