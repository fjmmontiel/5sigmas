Memory needs a governance schema

Provenance

Who or what produced the state?

Scope

User, tenant, session, agent or workflow?

Time

Created, validated, expired when?

Trust

User statement, trusted tool, external source or inference?

Revocation

How are derivatives invalidated?

Audit

Which decisions used the memory?

Write authority

The model may propose memory; the runtime decides whether it is persisted and which future actions it may influence.
