Security findings become release criteria

Authorization

No destructive effect without an independent boundary.

Memory isolation

No cross-tenant state leakage in regression fixtures.

Tool integrity

Schemas/scopes match the approved baseline.

Injection regression

Representative indirect-content paths run end-to-end.

Recovery

Kill path and rollback are verified.

Traceability

Every privileged action is reconstructable.

Why there is no universal pass percentage

The acceptance threshold follows the product's threat model. The important property is reproducibility and a direct connection between the test and a protected asset or effect.
