Deleting the source is not the same as removing its influence

Source

Original document or memory object.

Derivatives

Summaries, embeddings, caches and checkpoints.

Propagation

Other agents or workflows may copy the state.

Verification

Revocation must test future retrieval and behaviour.

Forget means behavioural evidence

A successful deletion API call is only one step. The system should demonstrate that the revoked information no longer influences protected decisions.
