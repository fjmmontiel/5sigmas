POST-TRANSFORMER DIRECTIONS

Three problems, three different responses

Mamba/SSMs, inference-time neural memory and continual-learning research target different Transformer frictions. They are not one universal replacement.

Mamba / selective state space models · long sequences
Problem

Standard attention has quadratic pairwise cost with sequence length.

Idea

Maintain a compact recurrent state with input-dependent selectivity, enabling linear sequence processing.

Trade-off

Compressed state is efficient, but it does not preserve every pairwise token interaction explicitly.

Titans-style neural memory · learning while using
Problem

Context is temporary and extending it indefinitely is expensive.

Idea

Add a learned long-term memory mechanism that can update during inference according to what appears worth remembering.

Trade-off

Updating and managing memory introduces extra complexity, latency and forgetting/interference questions.

Continual / nested learning · adaptation over time
Problem

Most deployed pretrained models are largely frozen; naïve fine-tuning can overwrite previous capabilities.

Idea

Use multiple adaptation mechanisms or optimization timescales so new information can be incorporated incrementally.

Trade-off

The stability–plasticity balance remains difficult at large scale.
