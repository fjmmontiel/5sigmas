AGENT LOOP

An agent is a loop, not an arrow

A useful agent observes, plans, acts, checks the result and updates memory before repeating. The goal stays at the center of the loop.

Observe→Plan→Execute→Verify→Memory↺
1 · Observe

Read the current environment: user messages, documents, images, system state and results from previous tool calls.

2 · Plan

Choose the next action relative to the objective. Complex tasks may be decomposed into subgoals and mapped to appropriate tools.

3 · Execute

Take an action: call an API, run code, search, write data or interact with a digital or physical environment.

4 · Verify

Evaluate whether the action produced the intended result. Failure adds new information and sends the system around the loop again.

5 · Update memory

Store relevant state before the next observation. External memory can persist across sessions; the immediate context window does not.
