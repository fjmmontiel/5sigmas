SEARCH AT INFERENCE TIME

From one prediction to exploring solutions

On hard problems, practical intelligence can require generating alternatives, evaluating them and allocating more computation to promising trajectories.

Direct prediction
Problem → Model → Answer

One trajectory. No explicit comparison among alternatives.

Model + search
Problem → Candidates → Evaluate → Select

Explore multiple trajectories and keep the best supported result.

2016 · AlphaGo

Neural networks + Monte Carlo tree search + reinforcement learning navigated the enormous Go search space.

2017 · AlphaZero

Self-play and search generalized the approach across Go, chess and shogi using the game rules rather than human game records.

2022 · ReAct

Language-model agents alternated reasoning and action, called tools, observed results and used those observations to choose subsequent steps.

2024–2025 · Search + verification expands

AlphaProof combined learned models with formal search and verification for olympiad mathematics; AlphaEvolve combined Gemini models, automated evaluators and evolutionary search for algorithm discovery.
