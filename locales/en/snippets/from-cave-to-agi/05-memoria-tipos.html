MEMORY

Three mechanisms, three different meanings of “remember”

A long context window, external retrieval and knowledge stored in model parameters have different persistence, cost and failure modes.

1 · Immediate context
systemconversationdocumentscurrent query
  • Available directly during the current inference.
  • Usually disappears when the active session/context is gone.
  • Longer context increases runtime cost.
2 · External memory / retrieval
Database / RAG → retrieve relevant records → insert into context
  • Can persist across sessions and scale beyond the context window.
  • The model only uses information that retrieval successfully surfaces.
  • Retrieval quality becomes part of system reliability.
3 · Parametric memory
W₁ · W₂ · W₃ · … · Wₙ
  • Knowledge compressed into weights during training.
  • Always available without a separate retrieval call.
  • Ordinary inference does not continuously update the pretrained weights.
Common mistake: a larger context window does not automatically become persistent memory, and RAG does not mean the model has permanently learned the retrieved document.
