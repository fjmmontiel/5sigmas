FOUNDATION MODEL PIPELINE

From raw data to product: three distinct stages

A foundation model is a reusable base, not a finished application. Pretraining, alignment and runtime orchestration solve different problems.

Stage 1 · Pretraining
Inputs

Books · web · code · articles · other broad corpora

→
Base model

Learns general statistical structure and reusable representations from a large self-supervised objective.

Goal: build broad capability. The result can be powerful without reliably following user instructions.

Stage 2 · Alignment / post-training
Inputs

Demonstrations · preference data · safety feedback · task-specific supervision

→
Aligned model

Better follows instructions, conversational conventions and behavioral constraints.

Methods can include supervised fine-tuning, preference optimization and reinforcement-learning variants.

Stage 3 · Runtime product
Runtime context

System instructions · tools · retrieval/RAG · session memory

→
Product

The model is orchestrated inside a system that provides current information, actions and product-specific behavior.

An assistant, agent or RAG application belongs here: the model is the engine, but the surrounding system determines much of the user experience.
