LEARNING SIGNAL

Where does the teacher come from?

Supervised

Examples include target labels.

email → spam / not spam
Unsupervised

No target label; the objective discovers structure.

customers → clusters
Self-supervised

The data creates its own prediction target.

context → next token
Reinforcement learning

A reward signal evaluates actions or outcomes.

state → action → reward
Architecture ≠ learning method

The same neural architecture can be trained with different learning signals. “Transformer” describes architecture; “self-supervised” describes how training targets are obtained.
