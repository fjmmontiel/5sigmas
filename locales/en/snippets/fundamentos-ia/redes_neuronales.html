Neural networks learn numerical weights

Training repeatedly changes weights and biases so the network's output better matches the objective.

Inputs→Weighted sums→Activations→Output score
Weights

Control how strongly each incoming signal affects a neuron.

Biases

Shift the activation threshold and give the unit additional flexibility.

Activations

Introduce nonlinearity so stacked layers can represent complex relationships.

Prediction→Loss→Backpropagation→Optimizer update
Loss

Measures how far the current prediction is from the training objective.

Backpropagation

Computes how each parameter contributed to the error.

Optimizer

Moves the parameters in small repeated steps that reduce accumulated loss.
