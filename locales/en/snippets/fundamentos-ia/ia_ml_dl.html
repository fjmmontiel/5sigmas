AI → ML → DL → GenAI

Four nested ideas. The useful question is what capability each layer adds.

Artificial IntelligenceThe broad umbrella: systems that plan, decide, search or optimize.
Typical input

Goal, constraints and environment state.

Typical output

A decision, plan, route or action policy.

Learning required?

Not necessarily. AI can also use rules, search and optimization.

Machine LearningAI systems that learn patterns from examples and generalize to new cases.
Typical input

Features, examples and sometimes labels.

Typical output

Predictions, scores, rankings, clusters or anomaly signals.

What it adds

The behavior is learned from data instead of written case by case.

Deep LearningMachine Learning based on deep neural networks, especially strong for images, audio and language.
Typical input

Complex signals: pixels, audio waveforms, tokens or frames.

Typical output

Recognition, embeddings and learned representations.

What it adds

Large neural networks learn useful features automatically from raw data.

Generative AIModern deep-learning systems whose primary output is new content.
Typical input

Prompt, context, examples and constraints.

Typical output

New text, images, audio, video or code.

What it adds

Generation: the model produces new samples rather than only a label or score.
