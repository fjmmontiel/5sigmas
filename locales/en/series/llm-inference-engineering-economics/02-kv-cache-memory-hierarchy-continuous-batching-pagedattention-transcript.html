Context occupies memory

Each token stores keys and values per layer and KV head. Precision also matters.

With 32 layers, 8 heads, dimension 128 and two bytes, that is 128 KiB per token.

For 4096 tokens, KV payload is 512 MiB. Weights and buffers are excluded.

Not all GPU memory is KV

Start with sixteen GiB in a simplified example.

Ten GiB hold weights, while two hold buffers and other reservations.

Four remain for KV. Request capacity depends on live state, not just FLOPs.

Separate logical and physical

The sequence needs six positions. Reserving a maximum of sixteen leaves ten unused.

With four-position blocks, a table maps those six positions to two physical blocks.

Two positions remain unused in the final block. Paging reduces waste; it does not eliminate it.

Completion frees a slot

A and B share a decode iteration. A finishes before B.

The scheduler frees A’s KV and admits C while B continues generating.

Continuous batching changes membership at each step. It is not the same as memory paging.

Moving state also costs

A block evicted from the GPU remains in CPU memory.

Reusing it requires crossing the interconnect and restoring residency.

More total capacity can add critical-path movement. Measure transfers and waiting, not just occupancy.

Cancellation releases state

A request reserves three blocks and keeps growing.

Cancellation stops the work and returns its blocks to the free pool.

Accounting must also close on errors. Orphaned blocks reduce capacity for later requests.
