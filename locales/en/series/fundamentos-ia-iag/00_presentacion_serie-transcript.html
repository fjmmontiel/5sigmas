What must the system produce?

A transaction may need a label; a question may need a written explanation.

Classification selects defined categories. Generation constructs a sequence of content.

The output format determines which errors we need to measure.

A model is not the entire product

The model transforms an input into a prediction or continuation.

The product adds context, permissions, tools and quality controls.

Changing those components can change the result without retraining the model.

Three questions, not three synonyms

The family describes the technique: for example, a neural network.

The signal describes how it learns: labels, data structure or reward.

The update describes what changes: here, the weights of that same network.

One request can use several components

A shop receives a message about returning an order.

A rule checks the deadline; a classifier identifies the message intent.

A generative model writes the reply using the policy and the rule result.

Training is one step, not completion

Separate training data from cases reserved for evaluation.

Deploy only the version that meets the criteria defined for the task.

Observe real errors and drift: a new version must pass evaluation again.

Capability and autonomy are different

A system may solve a difficult task while only making recommendations.

Another may perform simple actions with broad permissions.

Describe separately what it can do and what it is authorized to execute.
