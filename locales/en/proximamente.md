# Coming Soon

5sigmas is built as a growing technical learning library rather than a static collection of posts. New work is added when it improves one of three things: **technical depth, explanatory clarity or production usefulness**.

## What is expanding

### More complete learning paths

The current English library already covers AI and Generative AI foundations, reasoning models, multimodality, AI agents, AI security, AI infrastructure and the path from early representation systems to modern AI.

The next iterations deepen the links between those series so readers can move from concepts to implementation without losing the technical context.

### More production engineering

The Technical Articles section is focused on the contracts that matter when AI leaves the demo environment: realtime interaction, tool execution, durable state, observability, latency, barge-in, asynchronous work and failure recovery.

More notes will follow the same standard: explicit architecture, measurable trade-offs and reproducible engineering reasoning.

### Native English media

The English editorial and visual surface is being completed independently from media generation. Native English video, posters and article audio are added only when they are genuinely localized rather than inherited from Spanish.

This keeps language switching truthful and avoids presenting Spanish media as if it were an English equivalent.

### Interactive visual explanations

The visual layer will continue to grow around the same principle used throughout the current series: one concept per visual, responsive layouts, meaningful interaction and no decorative complexity that competes with the explanation.
